# AMI — porównanie sklepów

Statyczne porównanie ofert i zdjęć. Strona wejściowa: `index.html`. Zdjęcia znajdują się w `img/`.

## Otwieranie

Pobierz repozytorium przez **Code → Download ZIP**, rozpakuj cały katalog i otwórz `index.html` w przeglądarce. Zachowaj folder `img` obok pliku HTML. Nie jest potrzebna instalacja zależności.

## Dostęp

Repozytorium jest prywatne. Właściciel nadaje dostęp przez **Settings → Collaborators → Add people**. Zaproszona osoba musi zaakceptować zaproszenie na GitHubie.

GitHub wyświetla kod pliku HTML; aby zobaczyć stronę, otwórz pobraną kopię lokalnie.
